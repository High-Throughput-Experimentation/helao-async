- [ ] **Step 1: Write the failing test**

Create `helao/core/tests/test_ui_boundary.py`:

```python
"""Boundary gate on ``helao/ui/``: the UI layer may not import the legacy engine.

B0 moves the UI out of ``helao/core/servers/`` so that B1-B6 can replace the
engine underneath it. This test is what stops a port quietly reaching back into
legacy hosting from UI code -- an edge that would otherwise stay invisible until
B7 tried to delete ``helao/core/servers/``.

AST-walked rather than grepped, so a dynamic
``import_module("helao.core.servers...")`` is caught too: the Reflex stack
resolves panel modules from config strings, which a grep for ``from`` would miss
entirely.
"""

import ast
from pathlib import Path
from typing import Final

REPO_ROOT: Final[Path] = Path(__file__).resolve().parents[3]
UI_ROOT: Final[Path] = REPO_ROOT / "helao" / "ui"

#: Raised to the real module count by later B0 tasks. Its only job is to make an
#: empty or mis-rooted glob fail loudly instead of passing by reaching nothing.
MIN_UI_MODULES: Final[int] = 6

BANNED_PREFIX: Final[str] = "helao.core.servers"


def _ui_modules() -> list[Path]:
    return sorted(p for p in UI_ROOT.rglob("*.py") if "__pycache__" not in p.parts)


def _imported_names(tree: ast.AST) -> list[str]:
    """Every module name this AST references, statically or dynamically."""
    names: list[str] = []
    for node in ast.walk(tree):
        if isinstance(node, ast.Import):
            names.extend(alias.name for alias in node.names)
        elif isinstance(node, ast.ImportFrom):
            if node.module is not None and node.level == 0:
                names.append(node.module)
        elif isinstance(node, ast.Constant) and isinstance(node.value, str):
            # dynamic import targets and config-resolved module strings
            if node.value.startswith(BANNED_PREFIX):
                names.append(node.value)
    return names


def test_ui_tree_exists_and_is_not_empty() -> None:
    """Vacuity guard: an empty glob would make the boundary test pass for free."""
    assert UI_ROOT.is_dir(), f"{UI_ROOT} does not exist"
    modules = _ui_modules()
    assert len(modules) >= MIN_UI_MODULES, (
        f"only {len(modules)} modules under helao/ui/; expected at least "
        f"{MIN_UI_MODULES}. A mis-rooted glob passes the boundary test by "
        f"reaching nothing."
    )


def test_ui_does_not_import_the_legacy_engine() -> None:
    offenders: list[str] = []
    for path in _ui_modules():
        tree = ast.parse(path.read_text(encoding="utf-8"), filename=str(path))
        for name in _imported_names(tree):
            if name == BANNED_PREFIX or name.startswith(BANNED_PREFIX + "."):
                offenders.append(f"{path.relative_to(REPO_ROOT).as_posix()}: {name}")
    assert offenders == [], (
        "helao/ui/ must not import helao.core.servers -- the UI layer is being "
        "separated from the legacy engine that B7 deletes:\n  "
        + "\n  ".join(offenders)
    )
```

## Execution record (2026-08-14)

B0 is complete on `feat/legacy-separation-b0-ui-rehome` in all four repos. What
the plan got wrong, and what the execution found:

**1. `discovery.py` belongs in `shared/`, not `reflex/`.** The boundary test
caught `helao/ui/bokeh/vis_subscriber.py` importing
`helao.core.servers.reflex.discovery` — a Bokeh module depending on the Reflex
stack. The module's own docstring reads *"Deployment module resolution shared by
the Bokeh and Reflex UI stacks"*, and it imports only stdlib and `helao.helpers`.
Filing it under `shared/` removes the cross-stack edge rather than relocating it.
`PANEL_SUBPACKAGE = "reflex"` names a deployment subpackage, not a dependency.

**2. Four path-literal forms, not one.** A dotted-module substitution reaches
none of these, and each was found only by a red test:
- `from helao.core.servers import <module>` — the top-level package form. Broke
  `test_palette.py` collection outright (7 `palette` sites, 1 `bokeh_theme`).
- `os.path.join(REPO_ROOT, "helao", "core", "servers", ...)` — component form.
- `REPO_ROOT / "helao" / "core" / "servers" / ...` — `Path` component form.
- the same split across separate source lines (`test_reflex_entry_resolver`'s
  `_ENTRY`), which also needed one extra `dirname()` because `helao/ui` sits a
  level higher than `helao/core/servers`.

**3. File-level grep plus unrestricted line sed corrupts neighbouring lines.**
Task 3's substitution selected *files* containing an allowed symbol and then
rewrote *every* matching line in them, repointing three aliased
`import app_reflex as dbx/opx` statements at `helao.ui.shared`. Caught by the
full sweep (3 FAIL), not by the boundary test — correctly, since the offenders
are consumers outside `helao/ui/`. The plan called for a count check at that
step; it was skipped. **Restrict the sed to the matched symbols, or check the
count.**

**4. `REFLEX_STACK_GLOBS` must move with the Reflex modules, not with palette.**
Repointing it in the palette task would have left the Reflex-stack tests globbing
an empty match — passing vacuously — until Task 5. The collapse from 4 entries to
2 was verified to lose no file (47 files, both rename targets covered).

**5. `test_bokeh_theme`'s font sweep needed `helao/ui/**` too.** Its subject moved
out from under `helao/core/servers/**`; the glob would have kept reporting clean
while reaching nothing.

**6. Two environment traps that look like B0 defects and are not.** `launch.py`
spawns a bare `python`, so invoking it by absolute path leaves every child on the
OS interpreter (`No module named 'uvicorn'`). And `PYTHONPATH` must be
**absolute**: the Reflex backend is spawned with `cwd=<repo>/helao/ui/reflex/_app`,
where a relative `.` resolves to `_app` and `helao` becomes unimportable
(`No module named 'helao'`). Both produce failures that read exactly like a bad
move.

**7. Chrome reports Tailwind v4 colours as `oklch(...)`.** A render check that
parses `rgb(` sees nothing and reports "no element carried the tint" for a tint
that is correctly applied. Resolve computed colours through a 1×1 canvas so any
CSS colour space comes back as sRGB bytes.
