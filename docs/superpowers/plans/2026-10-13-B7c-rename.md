# B7c — Retire the hexagon routing layer and the `legacy` names: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to carry this plan out task by task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stations launch bare prefixes (`./helao.sh eche10`). The `helao/deploy/hexagon/` shim package, `hexconfig.py`, the `_hex` variants, the `fast|bokeh: graft` / `legacy_module:` / `deployment: hexagon` vocabulary, `makeActionApp`/`makeVisApp`, the Reflex hexagon seam and `adapters/legacy/` are gone from all four changing repos. Every non-orchestrator `ActionHost` binds the WS publish bridge in `__init__`, and preflight resolves every server the way the launcher does and rejects ambiguity. The resolved composition of every surviving config (ports, params, `root:`, imported module) is unchanged.

**Architecture:** Three phases across four repos, in the spec's merge order (D-B7c.10, Q1). **N1**: each of Deployment-A/B/C rewrites its configs and smoke drivers so nothing routes through the shims, checked against the *current* parent (`7592729b`). **P**: five ordered parent commits on `feat/b7c-rename`: (1) bridge into `ActionHost`; (2) configs; (3) delete the routing layer, collapse the Reflex seam, re-scope preflight; (4) `git mv adapters/legacy adapters/shared`; (5) ratchet, docs, stale references. **N2**: Deployment-A drops its import fallback; Deployment-A/B tighten their preflight pin. A scratch resolver (`$X/resolve.py`) computes the resolved composition R of every config; R0 (Task 0) is the reference every config edit is checked against.

**Tech Stack:** Python 3.14 (conda env `helao`), FastAPI, Bokeh, Reflex, pytest (one file per process), pyright (basic, authoritative), black 26.5.1.

**Spec:** `docs/superpowers/specs/2026-10-13-B7c-rename-design.md` (committed together with this plan). Every open question Q1–Q15 is taken at the spec's stated default. Where executing the spec literally was impossible or ambiguous, "Escalations" below records it; the controller has settled E1–E7 at the defaults written there, and E5 goes in the PR text.

`$X/mutate.py`:
```python
"""B7c: mutate-and-observe probes with a guaranteed, verified restore.

Usage: python mutate.py <tree> <probes.json>
Each probe: {"file": repo-relative path, "old": exact text (must occur once), "new": replacement,
             "test": pytest file or node id, "k": optional -k, "expect": substring of pytest output}
For each probe: sha256 the file, mutate, run pytest (300 s cap), restore in `finally`, verify the
sha256. RED = pytest exits non-zero and its output contains "expect". Exit 0 only if every probe
went RED and every file was restored byte for byte.
"""

import hashlib
import json
import signal
import subprocess
import sys
from pathlib import Path

TREE = Path(sys.argv[1])
for sig in (signal.SIGTERM, signal.SIGINT, signal.SIGHUP):
    signal.signal(sig, lambda *_: sys.exit(143))
bad = 0
for p in json.load(open(sys.argv[2], encoding="utf-8")):
    path = TREE / p["file"]
    orig = path.read_bytes()
    digest = hashlib.sha256(orig).hexdigest()
    text = orig.decode("utf-8")
    assert text.count(p["old"]) == 1, f'anchor not unique in {p["file"]}: {p["old"]!r}'
    mutated = text.replace(p["old"], p["new"]).encode("utf-8")
    cmd = [sys.executable, "-m", "pytest", "-q", "-p", "no:cacheprovider", "--color=no", p["test"]]
    if p.get("k"):
        cmd += ["-k", p["k"]]
    try:
        path.write_bytes(mutated)
        try:
            proc = subprocess.run(cmd, cwd=TREE, capture_output=True, text=True, timeout=300)
            rc, out = proc.returncode, proc.stdout + proc.stderr
        except subprocess.TimeoutExpired:
            rc, out = 124, "TIMEOUT"
    finally:
        path.write_bytes(orig)
    restored = hashlib.sha256(path.read_bytes()).hexdigest() == digest
    red = rc != 0 and p["expect"] in out
    bad += (not red) + (not restored)
    tail = " | ".join(out.strip().splitlines()[-3:])
    print(f'{"RED " if red else "NOT-RED"} restored={restored} {p["file"]} :: {p["test"]} :: {tail}')
sys.exit(1 if bad else 0)
```

- [ ] **Step 0.5: The resolver and its comparators.** Create `$X/resolve.py`:
```python
"""B7c: the resolved composition R of every config in a tree (read-only).

Usage: python resolve.py <tree> <out.json>        (PYTHONPATH must be <tree>)
Configs: helao/deploy/<d>/{configs,configs/archive,tests/smoke/configs}/*.{yml,py} for every
<d> on disk except hexagon, plus helao/hexagon/tests/smoke/configs/*.yml.
Per server it records the code key, the module the launcher imports (a hexagon shim mapped to
its LEGACY_MODULE, the orchestrator shim to hte's module of the same name, a graft to its
legacy_module), how fast_launcher.py:102-152's rule picked the deployment, the entry minus
the routing keys, and the D-B7c.2 edit (E10: only for entries with a routing key, or with no
deployment: whose pick is not unique/own once the shim package is ignored).
"""

import glob
import json
import os
import re
import sys
import traceback
from pathlib import Path

TREE = Path(sys.argv[1]).resolve()
sys.path.insert(0, str(TREE))
from helao.helpers.config_loader import read_config  # noqa: E402

DEPLOY = TREE / "helao" / "deploy"
ROUTING = ("fast", "bokeh", "reflex", "deployment", "legacy_module")
DROP_TOP = ("servers", "loaded_config_path", "helao_repo_root", "helao_credentials_path", "alert_config_path")
SHIM_RE = re.compile(r'^LEGACY_MODULE\s*=\s*"([^"]+)"', re.M)
VARIANT_RE = re.compile(r"""hexagon_variant\(.*?["']([^"']+\.(?:yml|py))["']""", re.S)


def config_files():
    out = []
    for d in sorted(DEPLOY.iterdir()):
        if not d.is_dir() or d.name.startswith(".") or d.name in ("hexagon", "__pycache__"):
            continue
        for sub in ("configs", "configs/archive", "tests/smoke/configs"):
            out += sorted((d / sub).glob("*.yml"))
            out += sorted(p for p in (d / sub).glob("*.py") if p.name != "__init__.py")
    out += sorted((TREE / "helao/hexagon/tests/smoke/configs").glob("*.yml"))
    return out


def dep_of(path):
    return os.path.basename(os.path.dirname(os.path.dirname(os.path.dirname(path))))


def pick(cfg_path, s, code, hide_hexagon):
    """fast_launcher.py's rule, with the same string operations."""
    if "deployment" in s:
        return s["deployment"], "explicit"
    search = os.path.dirname(os.path.dirname(os.path.dirname(cfg_path)))
    cands = sorted(glob.glob(os.path.join(search, "*", "servers", s.get("group", ""), f"{s[code]}.py")))
    if hide_hexagon:
        cands = [c for c in cands if dep_of(c) != "hexagon"]
    if not cands:
        return None, "none"
    if len(cands) == 1:
        return dep_of(cands[0]), "unique"
    own = [c for c in cands if c.startswith(os.path.dirname(os.path.dirname(cfg_path)))]
    return (dep_of(own[0]), "own") if own else (dep_of(cands[0]), "fallback")


def target(s, code, dep):
    if code == "reflex":
        return f"reflex:{s['reflex']}"
    mod, group = s[code], s.get("group")
    if dep is None:
        return None
    if dep == "hexagon":
        if mod == "graft":
            return s.get("legacy_module")
        if group == "orchestrator":
            return f"helao.deploy.hte.servers.orchestrator.{mod}"
        shim = DEPLOY / "hexagon" / "servers" / group / f"{mod}.py"
        m = SHIM_RE.search(shim.read_text(encoding="utf-8")) if shim.is_file() else None
        return m.group(1) if m else f"UNRESOLVED:{group}/{mod}"
    return f"helao.deploy.{dep}.servers.{group}.{mod}"


def edit(cfg_path, s, code, tgt):
    routed = "legacy_module" in s or s.get("deployment") == "hexagon" or s.get(code) == "graft"
    if code == "reflex":
        return {"drop": ["deployment"]} if s.get("deployment") == "hexagon" else None
    if tgt is None or tgt.startswith("UNRESOLVED") or not tgt.startswith("helao.deploy."):
        return {"error": f"target {tgt}"}
    D, M = tgt.split(".")[2], tgt.split(".")[-1]
    if not routed and "deployment" in s:
        return None  # E10: an existing explicit non-hexagon key is left alone
    bare = {k: v for k, v in s.items() if k not in ("legacy_module", "deployment")}
    bare[code] = M
    dep_after, how_after = pick(cfg_path, bare, code, hide_hexagon=True)
    in_configs = (
        os.path.basename(os.path.dirname(cfg_path)) == "configs"
        and os.path.basename(os.path.dirname(os.path.dirname(os.path.dirname(cfg_path)))) == "deploy"
    )
    need = dep_after != D or how_after in ("fallback", "none") or not in_configs
    if not routed and not need:
        return None
    return {code: M, "deployment": D if need else None}


out = {}
for f in config_files():
    rel = f.relative_to(TREE).as_posix()
    rec = {"variant_of": None, "top": {}, "servers": {}, "edits": {}}
    if f.suffix == ".py":
        m = VARIANT_RE.search(f.read_text(encoding="utf-8"))
        if m:
            rec["variant_of"] = (f.parent / Path(m.group(1)).name).relative_to(TREE).as_posix()
    try:
        cfg = read_config(str(f))
    except Exception:
        rec["error"] = traceback.format_exc(limit=1)
        out[rel] = rec
        continue
    rec["top"] = {k: v for k, v in cfg.items() if k not in DROP_TOP}
    for key, s in (cfg.get("servers") or {}).items():
        code = next((k for k in ("fast", "bokeh", "reflex") if k in s), None)
        if code is None:
            rec["servers"][key] = {"error": "no code key"}
            continue
        dep, how = pick(str(f), s, code, hide_hexagon=False) if code != "reflex" else (None, "reflex")
        tgt = target(s, code, dep)
        rec["servers"][key] = {"code": code, "target": tgt, "how": how,
                               "rest": {k: v for k, v in s.items() if k not in ROUTING}}
        e = edit(str(f), s, code, tgt)
        if e:
            rec["edits"][key] = e
    out[rel] = rec
json.dump(out, open(sys.argv[2], "w", encoding="utf-8"), indent=1, sort_keys=True, default=str)
print(f"configs={len(out)} servers={sum(len(r['servers']) for r in out.values())} "
      f"errors={sum(1 for r in out.values() if 'error' in r)} edits={sum(len(r['edits']) for r in out.values())}")
```

```python
"""B7c: compare a resolved composition against R0.

Usage: rcmp.py <R0.json> <R.json> [--only <prefix>]   compare every config in R (filtered)
       rcmp.py --variants <R0.json>                    each R0 variant equals its base
Compared per config: top-level keys; per server the import target and the entry minus the
routing keys. The code key, `how` and explicit deployment: values are not compared (D-B7c.5
pins are the only allowed difference, and they cannot change the target). Exit 0 iff equal.
"""

import json
import sys


def servers_view(rec):
    return {k: (v.get("target"), v.get("rest")) for k, v in rec["servers"].items()}


if sys.argv[1] == "--variants":
    r0 = json.load(open(sys.argv[2], encoding="utf-8"))
    bad = 0
    for rel, rec in sorted(r0.items()):
        base = rec.get("variant_of")
        if not base:
            continue
        same = base in r0 and servers_view(rec) == servers_view(r0[base]) and rec["top"] == r0[base]["top"]
        bad += not same
        print(f'{"SAME" if same else "DIFF"} {rel} -> {base}')
    sys.exit(1 if bad else 0)

r0, r1 = (json.load(open(p, encoding="utf-8")) for p in sys.argv[1:3])
only = sys.argv[sys.argv.index("--only") + 1] if "--only" in sys.argv else ""
diffs = []
for rel, rec in sorted(r1.items()):
    if not rel.startswith(only):
        continue
    if "error" in rec:
        diffs.append(f"{rel}: load error {rec['error'].strip()[-200:]}")
        continue
    if rel not in r0:
        diffs.append(f"{rel}: not in R0 (new config)")
        continue
    if rec["top"] != r0[rel]["top"]:
        diffs.append(f"{rel}: top-level keys differ")
    a, b = servers_view(r0[rel]), servers_view(rec)
    for k in sorted(set(a) | set(b)):
        if a.get(k) != b.get(k):
            diffs.append(f"{rel}:{k}: R0={a.get(k)} R={b.get(k)}")
gone = sorted(rel for rel in r0 if rel.startswith(only) and rel not in r1)
print("\n".join(diffs) if diffs else f"R-EQUAL {sum(1 for r in r1 if r.startswith(only))} configs")
print(f"deleted ({len(gone)}): " + " ".join(gone))
sys.exit(1 if diffs else 0)
```

```python
def _launcher_deployment(config_path: str, group: str, module: str):
    """fast_launcher.py:102-152's auto-detection, with its own string operations.

    Returns ``(deployment or None, candidate deployments)``. ``None`` with candidates
    means ambiguous: more than one deployment has the module, none is the config's own,
    and the launcher would take the first in sorted order (and only warn).
    The glob root is the config's great-grandparent, as in the launcher: for a smoke
    config that root holds no deployments, so every smoke entry needs deployment:.
    """
    search = os.path.dirname(os.path.dirname(os.path.dirname(config_path)))
    found = sorted(glob(os.path.join(search, "*", "servers", group, f"{module}.py")))
    deps = [os.path.basename(os.path.dirname(os.path.dirname(os.path.dirname(p)))) for p in found]
    if len(found) == 1:
        return deps[0], deps
    own_dir = os.path.dirname(os.path.dirname(config_path))
    own = [d for p, d in zip(found, deps) if p.startswith(own_dir)]
    return (own[0] if own else None), deps


def _module_resolution(cfg: dict, deploy_root: Path = DEPLOY_ROOT):
    """Gate 2: every fast:/bokeh: resolves to exactly one module on disk (D-B7c.5/6).

    Returns ``(issues, resolved)``; ``resolved`` maps server key to the deployment the
    launcher will import its module from. A reflex: server names a bundle, not a module,
    and is skipped. Retired hexagon routing keys are issues (D-B7c.2).
    """
    issues: list[str] = []
    resolved: dict[str, str] = {}
    config_path = str(cfg.get("loaded_config_path") or "")
    for key, s in (cfg.get("servers") or {}).items():
        retired = []
        if "legacy_module" in s:
            retired.append("`legacy_module:`")
        if s.get("deployment") == _RETIRED_DEPLOYMENT:
            retired.append("`deployment: hexagon`")
        if "graft" in (s.get("fast"), s.get("bokeh")):
            retired.append("a `graft` code key")
        if retired:
            issues.append(f"{key}: {', '.join(retired)} is retired hexagon routing; {_RULE}")
            continue
        module, group = _server_module(s), s.get("group")
        if not module:
            continue
        if not group:
            issues.append(f"{key}: no group:, so its module cannot be resolved")
            continue
        explicit = s.get("deployment")
        if explicit:
            if (deploy_root / explicit / "servers" / group / f"{module}.py").is_file():
                resolved[key] = explicit
            else:
                issues.append(f"{key}: deployment: {explicit} has no servers/{group}/{module}.py")
            continue
        dep, found = _launcher_deployment(config_path, group, module)
        if dep:
            resolved[key] = dep
        elif not found:
            issues.append(f"{key}: {group}/{module}.py exists in no deployment the launcher searches")
        else:
            issues.append(
                f"{key}: {group}/{module}.py exists in {found}, none of them this config's "
                f"own, so the launcher would pick '{found[0]}' by sorted order; add "
                f"deployment: <owner>"
            )
    return issues, resolved


def _checklist_presence(servers: dict, resolved: dict) -> tuple[list[str], list[str]]:
    """Gate 3 (Q15): look up the OWNING deployment's checklist only. Fail only when a
    checklist frozen at B7c's base is gone; report every other absence."""
    issues: list[str] = []
    notes: list[str] = []
    for key, s in servers.items():
        if s.get("group") != "action" or key not in resolved:
            continue
        module, owner = _server_module(s), resolved[key]
        cdir = _checklist_dir(owner)
        if cdir is not None and (cdir / f"{module}.json").exists():
            continue
        if cdir is not None and module in CHECKLISTS_AT_B7C.get(owner, frozenset()):
            issues.append(f"{key}: frozen endpoint checklist {module}.json is gone from {cdir}")
        else:
            notes.append(f"no checklist: {key} ({owner}/{module})")
    return issues, notes
```

```python
n = after["summary"]["filesAnalyzed"]

added_bad = {new: a[new] for old, new in pairs if old == "-" and a.get(new, 0)}
print(f"analyzed={n} worse={worse} added_with_errors={added_bad}")
sys.exit(1 if worse or added_bad else 0)
```
