# Pixi Environment Migration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the conda + uv `helao` environment with one pixi environment per host. Base pins are shared through a tracked `pixi.lock`; station packages are composed per host from the existing server-folder env files.

**Architecture:**
- The parent repo tracks a base-only `pixi.toml` + `pixi.lock`.
- A new module, `pixi_compose.py`, holds three pure parts: translating conda/pip specs to pixi entries, composing a host manifest, and lock seed/drift helpers.
- `helao_env.py` uses it to write an untracked `<repo>/.helao-env/pixi.toml` and run `pixi install`.
- All wrappers share one activation script, `activate_helao.sh` / `activate_helao.bat`. It uses `pixi shell-hook` and falls back to a conda `helao` env during the transition.

**Tech Stack:** pixi (latest release; 0.84.2 at spike time), Python 3.14, `tomllib` (stdlib) + `tomli-w`, `ruamel.yaml`, bash, Windows cmd, pytest.

**Spec:** `docs/superpowers/specs/2026-11-11-pixi-env-design.md`

## Global Constraints

- One helao environment per host. Every host moves (Linux and Windows); conda itself and every other conda env stay installed.
- No private deployment name may appear in any tracked parent-repo file. Refer to them as "private deployments". Check with `/bin/ls -1 helao/deploy` (plain `ls` is aliased to a coloured lister on fuyu and breaks greps).
- Server folders keep `environment.yml`, `environment_<plat>.yml`, `requirements.txt` and `pip_env_<plat>.yml`. Only folder-root files with exactly those names are read; any other yml, or any yml in a subfolder (e.g. `hte/servers/xafs/sidecar/environment-sim.yml`), is never read.
- The host workspace is `<repo>/.helao-env/`, untracked. Its platform list is the host platform only.
- `helao.sh` / `helao.bat` activate with `pixi shell-hook` and run `python launch.py` directly. Never `pixi run` (see `helao/helpers/CLAUDE.md`: PDEATHSIG, the Job Object, the raw console mode, `CTRL-d`).
- Transition fallback: no `.helao-env/pixi.toml`, but a conda env named `helao` exists, means a warning and `conda activate helao`. Neither existing means exit with "run setup_env".
- `black` on changed `.py` files right before every commit, in the repo that owns them.
- Subagents never run `git add`, `commit`, `push` or `stash`. Commit steps below are run by the controlling session after the task's review passes. Use `git -C <repo>` on every git call.
- Nothing under `/mnt/wd4`, `/mnt/st2`, `/mnt/k`, `/mnt/j` or `/mnt/i` is touched locally. note1 steps (Task 11) run over `ssh -o BatchMode=yes -i ~/.ssh/id_ed25519_note01 hte-note-01.caltech.edu`, and its sudo steps are run by the user.
- Commit messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Test interpreter until Task 10: the conda env, run from the repo root. In commands below, `PY` stands for `PYTHONPATH=/mnt/STORAGE/repos/helao/helao-async /home/dan/miniforge3/envs/helao/bin/python`. Type it out in full; the tool shell is zsh, which does not word-split a `$PY` variable.

## Review Focus

1. **CUDA host seeding:** note1 is a CUDA host, through its GPU server folder. The composed `platforms` entry must keep the lock platform key equal to the parent's (`linux-64`), or the seeded base pins are silently ignored, and drift reports every base package. Pinned by the `test_cuda_platform_entry_keeps_the_platform_name` test (Task 2) and the drift check in Task 11.
2. **Paths with spaces:** Windows checkouts under `C:\Users\First Last\...`. Every wrapper quotes `HA_DIR`/workspace paths. Pinned by bash wrapper tests that run from a directory whose name has a space (Tasks 5, 6). The `.bat` files are checked at the Windows gate (Task 12).
3. **First `update_env` after moving from conda, with no arguments:** the recorded prefixes lived in a conda env var, which pixi activation does not have yet. The run must say plainly that a station must run `setup_env <prefix>` once, and not silently pretend it updated the station. Pinned by `test_main_update_without_records_tells_a_migrating_host_to_pass_prefixes` (Task 4).
4. **Windows-edited `requirements.txt`:** CRLF line endings, inline `# comment` tails, blank lines. Must compose the same as clean files. Pinned by `test_pypi_spec_ignores_comments_blank_and_crlf` (Task 2).
5. **Workspace present but pixi missing:** a new shell without `~/.pixi/bin` on `PATH`. `activate_helao.sh` must find `~/.pixi/bin/pixi`, or fail with a message naming pixi, not with a bare `command not found`. Pinned by `test_activate_finds_pixi_in_home_bin` and `test_activate_without_pixi_names_it` (Task 5).

```python
from pathlib import Path

import pytest

import pixi_compose as pc

BASE = {
    "workspace": {
        "name": "helao",
        "channels": ["conda-forge"],
        "platforms": ["linux-64", "win-64"],
    },
    "dependencies": {"python": "3.14.*", "numpy": "*", "paramiko": "3.*"},
    "target": {
        "win-64": {
            "dependencies": {"comtypes": "*"},
            "activation": {"env": {"PYTHONPATH": "%PIXI_PROJECT_ROOT%"}},
        },
        "linux-64": {"activation": {"env": {"PYTHONPATH": "$PIXI_PROJECT_ROOT"}}},
    },
    "pypi-dependencies": {"uuid7": "*"},
}


def _folder(root: Path, name: str, **files: str) -> Path:
    f = root / name
    f.mkdir(parents=True)
    for fname, text in files.items():
        (f / fname.replace("__", ".")).write_bytes(text.encode("utf-8"))
    return f


@pytest.mark.parametrize(
    "line, want",
    [
        ("pyserial", ("pyserial", "*")),
        ("bokeh=3", ("bokeh", "3.*")),
        ("python=3.14", ("python", "3.14.*")),
        ("nodejs>=22.12", ("nodejs", ">=22.12")),
        ("setuptools<82", ("setuptools", "<82")),
        ("conda-forge::jupyterlab", ("jupyterlab", "*")),
        ("pytorch=*=cuda129*", ("pytorch", {"version": "*", "build": "cuda129*"})),
        ("x=1.2=py_0", ("x", {"version": "1.2.*", "build": "py_0"})),
    ],
)
def test_conda_spec(line, want):
    assert pc.conda_spec(line) == want

        ("x==1.0", ("x", "==1.0", None)),

            'comtypes; sys_platform == "win32"',
            ("comtypes", "*", 'sys_platform == "win32"'),

def test_pypi_spec_ignores_comments_blank_and_crlf(tmp_path):

        tmp_path, "a", requirements__txt="# hdr\r\n\r\nfabio  # tiff io\r\nzaber-motion\r\n"

def test_unmapped_url_requirement_is_an_error():

def test_compose_folds_host_target_and_keeps_host_platform_only(tmp_path):
    m = pc.compose(BASE, set(), "win-64", tmp_path)
    assert m["workspace"]["platforms"] == ["win-64"]
    assert "target" not in m
    assert m["dependencies"]["comtypes"] == "*"
    m = pc.compose(BASE, set(), "linux-64", tmp_path)
    assert "comtypes" not in m["dependencies"]


def test_compose_sets_absolute_activation(tmp_path):
    states = [tmp_path / "r1/STATES/s.json", tmp_path / "r2/STATES/s.json"]
    m = pc.compose(BASE, set(), "linux-64", tmp_path, states)

def test_compose_reads_root_env_files_for_the_host_platform_only(tmp_path):
```

```python
"""Compose a host pixi manifest from the tracked base manifest and the env
files of a station's server folders; seed and check the host lock.

Used by helao_env.py. No pixi calls and no helao imports, so every rule is
testable offline. Spec: docs/superpowers/specs/2026-11-11-pixi-env-design.md.
"""

from __future__ import annotations

import copy
import re
import sys
from pathlib import Path

#: A URL requirement names no package; map the URL's repo name to the dist
#: name its metadata declares (pixi refuses a mismatch).
URL_DIST_NAMES = {"pyMeCom": "mecom"}

_CUDA_BUILD = re.compile(r"^cuda(1\d)(\d)")
_WIN_MARKER = re.compile(r"""sys_platform\s*(==|!=)\s*['"]win32['"]""")
_NAME = re.compile(r"^([A-Za-z0-9_.\-]+)(\[[^\]]*\])?\s*(.*)$")


class ComposeError(Exception):
    """An env file pixi cannot express, or two folders that disagree."""


def _yaml():
    from ruamel.yaml import YAML

    return YAML(typ="safe")


def conda_spec(line: str) -> tuple[str, str | dict]:
    """(name, pixi spec) for one conda dependency string."""
    s = line.strip().split("::")[-1]
    m = re.match(r"^([A-Za-z0-9_.\-]+)\s*(.*)$", s)
    if not m:
        raise ComposeError(f"cannot read conda spec {line!r}")
    name, rest = m.group(1), m.group(2).strip()
    if not rest:
        return name, "*"
    if rest.startswith("=") and not rest.startswith("=="):
        version, _, build = rest[1:].partition("=")
        if "*" not in version:
            version += ".*"
        return name, ({"version": version, "build": build} if build else version)
    return name, rest


def _extras(bracket: str | None) -> list[str]:
    return [e.strip() for e in bracket[1:-1].split(",") if e.strip()] if bracket else []


def pypi_spec(line: str) -> tuple[str, str | dict, str | None] | None:
    """(name, pixi spec, marker) for one requirements.txt line; None if blank."""
    s = line.strip()
    if not s or s.startswith("#"):
        return None
    s = s.split(" #", 1)[0].strip()
    if s.startswith("-"):
        raise ComposeError(f"requirements option {s!r} is not supported")
    marker = None
    if ";" in s:
        s, marker = (x.strip() for x in s.split(";", 1))
    if s.startswith(("http://", "https://")):
        parts = s.rstrip("/").split("/")
        name = URL_DIST_NAMES.get(parts[-3]) if len(parts) >= 3 else None
        if name is None:
            raise ComposeError(
                f"URL requirement {s!r}: add its dist name to URL_DIST_NAMES"
            )
        return name, {"url": s}, marker
    if " @ " in s:
        req, url = (x.strip() for x in s.split(" @ ", 1))
        m = _NAME.match(req)
        if not m:
            raise ComposeError(f"cannot read requirement {line!r}")
        spec: dict = {"git": url[4:]} if url.startswith("git+") else {"url": url}
        if m.group(2):
            spec["extras"] = _extras(m.group(2))
        return m.group(1), spec, marker
    m = _NAME.match(s)
    if not m:
        raise ComposeError(f"cannot read requirement {line!r}")
    name, ver = m.group(1), m.group(3).strip() or "*"
    if m.group(2):
        return name, {"version": ver, "extras": _extras(m.group(2))}, marker
    return name, ver, marker


def _cuda_of(spec) -> str | None:
    if isinstance(spec, dict):
        m = _CUDA_BUILD.match(str(spec.get("build", "")))
        if m:
            return f"{m.group(1)}.{m.group(2)}"
    return None


def _stderr(msg: str) -> None:
    print(f"warning: {msg}", file=sys.stderr)


def compose(
    base: dict,
    folders,
    platform: str,
    repo_root: Path,
    states_files=(),
    pip_env_for=None,
    warn=None,
) -> dict:
    """Host manifest: ``base`` for ``platform`` only, plus every folder's
    root env files merged into the default environment.

    ``pip_env_for(folder) -> {VAR: template}`` supplies a folder's pip_env
    overrides (``{prefix}``/``{PATH}`` templates); ``warn(msg)`` reports a
    folder overriding a base spec.
    """
    warn = warn or _stderr
    win = platform.startswith("win")
    var = (lambda n: f"%{n}%") if win else (lambda n: f"${n}")
    m = copy.deepcopy(base)
    here = (m.pop("target", None) or {}).get(platform, {})
    deps = {**m.get("dependencies", {}), **here.get("dependencies", {})}
    pypi = {**m.get("pypi-dependencies", {}), **here.get("pypi-dependencies", {})}
    act = {
        **m.get("activation", {}).get("env", {}),
        **here.get("activation", {}).get("env", {}),
    }
    owners: dict[tuple[str, str], tuple[Path, object]] = {}

    def add(table: dict, kind: str, name: str, spec, folder: Path) -> None:
        key = (kind, name.lower())
        if key in owners:
            prev_folder, prev = owners[key]
            if prev != spec:
                raise ComposeError(
                    f"{name}: {prev_folder} wants {prev!r} but {folder} wants {spec!r}"
                )
            return
        owners[key] = (folder, spec)
        if name in table and table[name] != spec:
            warn(f"{folder} overrides base {name} {table[name]!r} with {spec!r}")
        table[name] = spec

    def add_pypi(line: str, folder: Path) -> None:
        parsed = pypi_spec(line)
        if parsed is None:
            return
        name, spec, marker = parsed
        if marker is not None:
            mk = _WIN_MARKER.fullmatch(marker)
            if not mk:
                raise ComposeError(
                    f"{folder}: marker {marker!r} is not supported "
                    '(only sys_platform == / != "win32")'
                )
            if (mk.group(1) == "==") != win:
                return
        add(pypi, "pypi", name, spec, folder)

    for folder in sorted(Path(f) for f in folders):
        for fname in ("environment.yml", f"environment_{platform}.yml"):
            f = folder / fname
            if not f.is_file():
                continue
            data = _yaml().load(f.read_text(encoding="utf-8")) or {}
            for d in data.get("dependencies") or []:
                if isinstance(d, dict):
                    for line in d.get("pip") or []:
                        add_pypi(str(line), folder)
                else:
                    add(deps, "conda", *conda_spec(str(d)), folder)
        req = folder / "requirements.txt"
        if req.is_file():
            for line in req.read_text(encoding="utf-8").splitlines():
                add_pypi(line, folder)
        for k, v in (pip_env_for(folder) or {} if pip_env_for else {}).items():
            v = v.replace("{prefix}", var("CONDA_PREFIX")).replace("{PATH}", var("PATH"))
            key = ("env", k)
            if key in owners and owners[key][1] != v:
                raise ComposeError(
                    f"{k}: {owners[key][0]} sets {owners[key][1]!r} but {folder} sets {v!r}"
                )
            owners[key] = (folder, v)
            act[k] = v

    if "pytorch-cpu" in deps and _cuda_of(deps.get("pytorch")):
        del deps["pytorch-cpu"]  # CUDA pytorch overrides pytorch-cpu
    cudas = {c for c in map(_cuda_of, deps.values()) if c}
    if len(cudas) > 1:
        raise ComposeError(f"conflicting CUDA builds: {sorted(cudas)}")
    m["workspace"]["platforms"] = (
        [{"name": f"{platform}-cuda", "platform": platform, "cuda": cudas.pop()}]
        if cudas
        else [platform]
    )
    act["PYTHONPATH"] = str(repo_root)
    act["HELAOLAUNCH"] = str(Path(repo_root) / ("helao.bat" if win else "helao.sh"))
    act["HELAO_STATION_PREFIXES"] = (";" if win else ":").join(
        sorted(str(p) for p in states_files)
    )
    m["dependencies"] = deps
    m["pypi-dependencies"] = pypi
    m.setdefault("activation", {})["env"] = act
    return m


def platform_key(manifest: dict) -> str:
    """Lock platform key of a composed manifest's single platform."""
    (entry,) = manifest["workspace"]["platforms"]
    return entry["name"] if isinstance(entry, dict) else entry
```

```python
import hashlib
import shutil


def seed_lock(parent_lock: Path, workspace: Path, platform: str, host_key: str) -> bool:
    """Copy the parent lock over the host lock when the host has none or the
    parent changed since the last seed (sha256 kept in ``.seed``). A CUDA
    host's platform is keyed ``<plat>-cuda``, so the copy's ``platform`` key
    is renamed to ``host_key`` for pixi to keep the seeded versions."""
    sha = hashlib.sha256(Path(parent_lock).read_bytes()).hexdigest()
    seed, host = Path(workspace) / ".seed", Path(workspace) / "pixi.lock"
    if host.is_file() and seed.is_file():
        if seed.read_text(encoding="utf-8").strip() == sha:
            return False
    if host_key == platform:
        shutil.copyfile(parent_lock, host)
    else:
        yaml = _yaml()
        data = yaml.load(Path(parent_lock).read_text(encoding="utf-8"))
        for env in (data.get("environments") or {}).values():
            pk = env.get("packages") or {}
            if platform in pk:
                pk[host_key] = pk.pop(platform)
        with open(host, "w", encoding="utf-8") as fh:
            yaml.dump(data, fh)
    seed.write_text(sha + "\n", encoding="utf-8")
    return True


def _conda_dist(url: str) -> tuple[str, str] | None:
    fname = url.rsplit("/", 1)[-1]
    for ext in (".conda", ".tar.bz2"):
        if fname.endswith(ext):
            name, version, _build = fname[: -len(ext)].rsplit("-", 2)
            return name, version
    return None


def lock_versions(lock: Path, platform: str, env: str = "default") -> dict[str, str]:
    """{package name (lower case): version} of one env and platform in a lock."""
    data = _yaml().load(Path(lock).read_text(encoding="utf-8")) or {}
    meta = {p.get("conda") or p.get("pypi"): p for p in data.get("packages") or []}
    envs = (data.get("environments") or {}).get(env) or {}
    out: dict[str, str] = {}
    for ref in (envs.get("packages") or {}).get(platform) or []:
        url = ref.get("conda") or ref.get("pypi")
        p = meta.get(url) or {}
        if "name" in p and "version" in p:
            out[str(p["name"]).lower()] = str(p["version"])
        elif ref.get("conda") and (d := _conda_dist(url)):
            out[d[0].lower()] = d[1]
    return out


def drift(parent_lock: Path, host_lock: Path, platform: str, host_key: str | None = None):
    """Base packages whose host version differs: [(name, parent, host|None)]."""
    base = lock_versions(parent_lock, platform)
    host = lock_versions(host_lock, host_key or platform)
    return sorted((n, v, host.get(n)) for n, v in base.items() if host.get(n) != v)
```
